# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Existing stack: React, TypeScript, Vite, Express, Prisma, PostgreSQL, Redis, and Python utilities. The brief requests a configurable OpenAI/Anthropic provider layer and web-based workflows that preserve the Python utilities.

## Users

Entrepreneurs, marketing agencies, and marketing teams who need to audit websites, understand competitors, improve SEO, plan campaigns, and produce marketing content without using a terminal or programming tools.

## Product Purpose

Turn the AIScripto AI Marketing Suite's command-based marketing workflows into a web application. Success means users can configure a marketing project, run the original analysis and content workflows from a graphical interface, review evidence and recommendations, and keep their work and reports in a workspace.

## Positioning

The application carries the existing AIScripto marketing skills, five specialist agent definitions, weighted audit methodology, Python analysis utilities, templates, and Markdown/PDF deliverables into project-based workflows.

## Operating Context

Users work across projects and workspaces. The central workflows include website audits, SEO and competitor analysis, copy and campaign creation, content planning, proposals, and client-ready reports. Results need to persist and remain available for comparison and export.

## Capabilities and Constraints

- Preserve all 14 commands and all six audit score weights: content 25%, conversion 20%, SEO 20%, competitive positioning 15%, brand and trust 10%, growth and strategy 10%.
- Preserve original Markdown and PDF report outputs and reusable templates.
- Distinguish crawl-verified findings from AI recommendations and estimates.
- Do not present external performance data or integration status without a connected, working data source.
- AI generation requires a configured provider credential stored server-side. There are no provider or OAuth credentials in the repository.
- Ads and social publishing remain draft workflows until a real publisher integration is configured and succeeds.
- The checked-out AIScripto repository is authoritative; stale upstream links in the original README are not product dependencies.
- Support workspace data isolation, multiple projects, execution history, and light and dark themes. Light mode is the initial theme.

## Brand Commitments

Product name: AI Marketing Suite. Company: AIScripto. Website: https://www.aiscripto.com. The supplied brief calls for a professional, premium, restrained marketing SaaS interface and names Linear, HubSpot, Semrush, and modern AI SaaS products as references. The repository contains a CLI banner but no confirmed production logo asset; do not invent a logo or brand claims.

## Evidence on Hand

The repository contains the existing command router (`market/SKILL.md`), 14 workflow specifications (`skills/`), five specialist agent definitions (`agents/`), four Python utilities (`scripts/`), six templates (`templates/`), and an MIT license. No customer evidence, integration credentials, production logo, or live metrics are present.

## Product Principles

- Make every existing command workflow reachable through the interface.
- Preserve the source methodology and reusable assets.
- Show evidence and provenance for findings.
- Persist project work and execution results.
- Report configuration gaps and failures honestly.
